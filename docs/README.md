# Documentation

Ce dossier regroupe les documents qui ne sont pas nécessaires à l’exécution de
l’application.

```text
docs/
├── revue-projet.md            # support de la revue de projet (rendu 4)
├── presentation.pptx          # présentation du projet
├── presentation-gio.pdf       # autre support de présentation
├── choix-de-la-ville.md        # contexte initial autour de La Clusaz
├── sujet/                      # consignes et documents attendus
├── schemas/                    # schémas et illustrations complémentaires
└── cours/                      # supports de cours PDF
```

Le code, les schémas techniques et les exemples utilisés par l’application
restent dans `src/` afin que le serveur puisse les retrouver directement.
